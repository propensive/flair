# `F6` — Indent width must be even

**Principle:** F — The Frame

Raised by flair when a non-blank line's
leading spaces are not a multiple of 2.

## Cause

Consequent Style indents in steps of two columns.

## Example message

```
[↯F6] indent width 3 is not a multiple of 2
```

## Resolution

Adjust the indentation to the nearest multiple of 2.
