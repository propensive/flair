# `C3` — Continuation indents after `=>` and heavy `:`

**Principle:** C — Continuation Marking

Raised by flair when a continuation line
following a `=>` or heavy-signature `:` does not have the required
fixed indent.

## Cause

A `=>` continuation line must be followed by exactly two spaces; a
heavy-signature return-type `:` continuation must be followed by
exactly three spaces.

## Example messages

```
[↯C3] `=>` continuation line must be followed by exactly two spaces
```

```
[↯C3] heavy-signature return type `:` must be followed by exactly three spaces
```

## Resolution

Adjust the leading whitespace on the continuation line to match.
