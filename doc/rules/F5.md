# `F5` — Tab characters

**Principle:** F — The Frame

Raised by flair when a tab character appears
anywhere in source.

## Cause

Consequent Style requires that all indentation and intra-line spacing
use spaces, not tabs.

## Example message

```
[↯F5] tab character is not permitted; use spaces
```

## Resolution

Configure the editor to insert spaces; replace any existing tabs
with the appropriate number of spaces.
