# `F3` — Blank line after `package`

**Principle:** F — The Frame

Raised by flair when line `header + 2` (immediately
after the `package` declaration) is not blank.

## Cause

A single blank line must separate the `package` declaration from
whatever follows.

## Example message

```
[↯F3] line `header + 2` must be a single blank line after `package`
```

## Resolution

Insert a single blank line on line `header + 2`.
