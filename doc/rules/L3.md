# `L3` — `object` must precede `class`/`trait`/`enum` of same name

**Principle:** L — Locatability

Raised by flair when a companion `object`
appears below the type it accompanies.

## Cause

Consequent Style places the companion `object` before the
`class`/`trait`/`enum` it pairs with.

## Example message

```
[↯L3] object `Foo` must appear before class/trait/enum `Foo`
```

## Resolution

Move the `object` declaration above the type declaration.
