# `A9` — Quote and splice layout

**Principle:** A — Anchoring

Raised by flair when the layout of a quoted or spliced block is broken.

## Cause

The layout of a quoted or spliced block is prescribed in detail: where the
opener sits, how far the body is indented, where the closing brace goes, and
what spacing surrounds an inline quote. Staged code then reads consistently
with the code around it.

The rules of this family are contractually frozen; their normative text and
examples are in the standard.

## Variants

| Code | Message |
| --- | --- |
| `A9.1` | closing `}` of a multi-line quote/splice at column <cols> does not align with its opening `{` at column <opener> |
| `A9.2` | `<arr>` and `{` of a multi-line quote/splice must be separated by exactly one space |
| `A9.3` | the `<arr> {` opener of a multi-line quote/splice must be alone on its line (only enclosing `(` / `{` permitted) |
| `A9.4` | body of a multi-line quote/splice must be indented to column <top> (found <leadingCols>) |
| `A9.5` | closing `}` of a multi-line quote/splice must be alone on its line (only trailing `)` / `}` permitted) |
| `A9.6` | no space is permitted directly after `<prefix><text>` in an inline quote/splice |

## Resolution

Follow the layout the message names; the sub-code identifies which aspect is at
fault.
