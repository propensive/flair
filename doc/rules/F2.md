# `F2` — `package` declaration on line `header + 1`

**Principle:** F — The Frame

Raised by flair when line `header + 1` is not
`package <module>` matching the source's module.

## Cause

After the 32-line licence header, line `header + 1` must declare the package.
The package name must be a single identifier segment matching the
file's expected module.

## Example messages

```
[↯F2] expected `package` declaration on line `header + 1`, found content on line 34
```

```
[↯F2] package declaration must be a single identifier segment, not `foo.bar`
```

```
[↯F2] package `foo` does not match expected module `bar`
```

```
[↯F2] package declaration must contain only `package <ident>` on line `header + 1`
```

```
[↯F2] line `header + 1` must be `package <module>`
```

## Resolution

Place a single `package <module>` declaration on line `header + 1`, where
`<module>` is the module the file belongs to.
